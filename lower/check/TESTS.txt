TESTS.txt: test log for lower/check/lowcheck.c (2026-10-26)

Machine: 10-core Apple Silicon Mac, 24 GB, shared with a background klow run at nice 10 on
8 threads (load average 20 to 26 during these runs). Every run used 6 threads.
All commands run from lower/check/. Build: clang -O3 -march=native -lpthread lowcheck.c -o lowcheck
(no warnings under -Wall -Wextra -Wconversion).

Interface: "lowcheck k h witness.bin [threads] [claimed_r]" is the spec's. Two extra modes exist
only to run the spec's tests: "--brute k h witness.bin [threads]" (TEST 1) and
"--count k h [threads]" (TEST 2 for sizes with no witness file). Every run also prints an
independent class count from Burnside's lemma over S_k x swap and exits 2 if it disagrees.

SUMMARY

TEST 1, brute force, all 11 witnesses (k^(2h) from 64 to 60,466,176): every check PASS in all 11.
  - rank equals the lexicographic position found by scanning all k^(2h) strings; unrank and the
    successor function agree with it.
  - every pair lands on a set bit; swap and letter permutations keep the class (all of S_k for
    k <= 5; for k = 6, 7, 10 the k-1 adjacent transpositions, which generate S_k, plus 8 random
    permutations); every class is hit; for k <= 5 the brute-force orbit count equals the class
    count and no class spans two orbits.
  - T at every pair, computed from the definition with base-k index arithmetic on the expanded
    vector, equals its class representative's T; min and max of T - w over all pairs equal the
    class-based r and max.
TEST 2, class counts: all 12 claimed counts reproduced, each equal to the Burnside count.
